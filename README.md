# 成语高手 · 拼音筛选台

一个完全在浏览器本地运行的成语筛选工具。可以为成语的每一个字位分别指定汉字、声母、韵母和声调，并将这些条件组合筛选。

## 功能

- 支持 3–9 字成语，默认筛选四字成语
- 每个字位可独立指定：汉字、声母、韵母、一至四声或轻声；声韵母直接打字并提供候选提示
- “全成语包含”支持添加多组条件：每一组都必须在成语的某个字中命中
- “全成语排除”支持添加多组条件：任意一组命中时剔除整条成语
- 默认提供 4 组包含条件和 6 组排除条件，重置后恢复这一数量
- 每一组内部使用“或”逻辑：声母或韵母任意一个匹配，该组即命中
- 支持零声母以及 `ü / üe / üan / ün`，输入 `v` 或 `u:` 会自动转换为 `ü`
- 支持汉字、带空格或不带空格的无调拼音搜索
- 支持按近似语料常用度筛选：高频、常见、较少见、低频/未收录
- 结果展示逐字的声母、韵母、声调拆分
- 支持一键复制、CSV 导出、移动端响应式界面
- 成语数据与拼音解析均在本地完成，不依赖在线接口

## 技术选型

- [`pinyin-pro`](https://github.com/zh-lx/pinyin-pro)：整词拼音与多音字处理，并返回逐字声母、韵母、数字声调。项目维护活跃、MIT 许可。
- [`cnchar-idiom`](https://github.com/theajack/cnchar)：随 npm 包离线分发的成语词库，MIT 许可。本工具清理后载入 30,192 条纯汉字词条，其中 29,349 条为四字成语。
- [`jieba`](https://github.com/fxsjy/jieba)：使用词典中的语料频次生成离线常用度索引。分级阈值为高频 ≥100、常见 20–99、较少见 4–19、低频/未收录 ≤3。
- React + Vite：构建响应式单页图形界面。

`pinyin-pro` 为使用便利将 `y`、`w` 视作声母，本工具沿用这一约定；“阿”等无声母音节可选择“零声母”。筛选使用词典本调，关闭“一/不”的语流变调，适合成语字典查询。

常用度是基于 `jieba` 语料词频的近似分级，不代表规范词典结论；“未收录”与低频合并展示，避免把缺失数据误判为绝对生僻。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址，通常为 `http://127.0.0.1:5173/`。

生产构建：

```bash
npm run build
npm run preview
```

## 测试

```bash
npm test
```

测试覆盖音调去除、`ü` 保留、逐字声韵调解析、组合筛选、零声母和连续拼音搜索。
