# 成语高手简易使用教程

“成语高手”是一款离线成语筛选工具，可以按照字数、常用程度、固定字位的汉字、拼音声母、韵母和声调查找成语。

## 1. 安装与启动

### Windows 桌面版

1. 双击 `成语高手_1.0.0_x64-setup.exe`。
2. 按安装向导完成安装。
3. 从开始菜单或桌面快捷方式打开“成语高手”。

应用默认安装到当前 Windows 用户目录，不需要管理员权限。首次打开如果 Windows 显示“未知发布者”，是因为个人构建版本没有商业代码签名证书；请确认安装包来源可信后再继续。

### 浏览器开发版

在项目目录打开 PowerShell：

```powershell
npm install
npm run dev
```

然后访问 `http://127.0.0.1:5173/`。终端窗口需要保持开启。

## 2. 基础筛选

### 字数

在“字数”下拉框中选择三字、四字或其他长度。切换字数后，下方会出现对应数量的字位筛选卡片。

### 常用度

可以选择：

- 全部
- 高频
- 常见
- 较少见
- 低频 / 未收录

常用度来自离线语料词频，只适合辅助排序和缩小范围，不代表规范词典结论。

### 搜索框

搜索框支持：

- 汉字，例如 `龙`
- 无调拼音，例如 `hualong`
- 带空格的拼音，例如 `hua long`

## 3. 固定字位筛选

每个字位都可以设置：

- 指定汉字
- 声母
- 韵母
- 声调

同一字位填写的条件需要同时满足。例如第一字位设置声母 `h`、韵母 `ua`、四声，会匹配读作 `huà` 的字。

声母、韵母直接打字输入：

- 声母示例：`b`、`l`、`zh`
- 韵母示例：`a`、`ong`、`iang`
- 输入 `v` 或 `u:` 会自动转换为 `ü`
- 零声母可输入 `零声母` 或 `∅`

点击已经选中的声调可以取消该声调。点击字位卡片右上角的清除按钮，只会清除该字位条件。

## 4. 全成语“包含”与“排除”

这两类条件不限制字的位置，而是在整个成语中查找。

### 包含

每一组包含条件都必须命中成语中的某个字。一个组内如果同时填写声母和韵母，只要其中一个匹配，该组就算命中。

例如：

- 第 1 组填写声母 `l`
- 第 2 组填写韵母 `ing`

表示成语中必须存在一个声母为 `l` 的字，同时还必须存在一个韵母为 `ing` 的字；它们可以是同一个字，也可以是不同的字。

### 排除

任意一组排除条件命中后，整条成语都会被剔除。组内同样使用“声母或韵母任意一个匹配”的逻辑。

例如排除组填写声母 `sh`、韵母 `ong`，只要成语中出现声母 `sh` 或韵母 `ong` 的字，该成语就会被排除。

可以使用“添加”增加条件，使用垃圾桶按钮删除条件，使用“清空”一次清除全部包含与排除内容。

## 5. 查看与导出结果

- 点击结果卡片可以选中成语，选中项会显示边框。
- 点击卡片右上角的复制按钮，可复制成语及标准汉语拼音。
- 点击“导出 CSV”可保存当前全部筛选结果。
- 结果少于 50 条时，会自动按照离线语料词频从高到低排序，但页面不会显示具体频率数值。

## 6. 一个完整示例

查找读音为 `huà lóng diǎn jīng` 的四字成语：

1. 字数选择 `4 字`。
2. 第一字位输入声母 `h`、韵母 `ua`，选择四声。
3. 第二字位输入声母 `l`、韵母 `ong`，选择二声。
4. 第三字位输入声母 `d`、韵母 `ian`，选择三声。
5. 第四字位输入声母 `j`、韵母 `ing`，选择一声。

结果会筛出“画龙点睛”。也可以直接点击页面上方示例区域的“填入条件”。

## 7. 常见问题

### 没有结果

先减少一个条件，重点检查声调、`ü`、零声母和多音字读法。也可以点击“重置”恢复默认状态。

### 输入声母或韵母时没有候选菜单

这是正常设计。声母和韵母使用纯文本输入，不会弹出下拉选择栏。

### CSV 在 Excel 中显示异常

导出的 CSV 已包含 UTF-8 BOM。若仍乱码，请在 Excel 中通过“数据 → 从文本/CSV”导入，并选择 UTF-8 编码。

### Windows 阻止安装

确认安装包来自本项目后，可在 SmartScreen 提示中选择“更多信息”，再选择“仍要运行”。不要运行来源不明的同名安装包。

## 8. 开发者命令

```powershell
# 自动测试
npm test

# 浏览器生产构建
npm run build

# Tauri 桌面开发模式
npm run desktop:dev

# 生成 Windows NSIS 安装程序
npm run desktop:build
```

桌面安装包默认生成在：

```text
src-tauri/target/release/bundle/nsis/
```
